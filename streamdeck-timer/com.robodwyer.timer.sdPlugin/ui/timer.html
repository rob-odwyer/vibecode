How to use

Enter a duration in plain language — 1h 30m, 90s, 5 min, 2h (a bare number like 90 means 90 seconds). Changing the duration resets the timer. Use the Title field above to label the key. Press the key to start or pause. Press and hold to reset to the full duration. The ring shrinks and shifts green → amber → red as time runs out, then flashes red when the timer expires (press to dismiss).
