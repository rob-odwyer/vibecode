# Timer — Stream Deck plugin

A configurable countdown timer for a single Stream Deck key (built with the Stream Deck
**Mini** in mind — no dial required). Set a title and a duration in plain language
(`1h 30m`, `90s`, `5 min`, or a bare `90` for 90 seconds — parsed with
[`parse-duration`](https://www.npmjs.com/package/parse-duration), with the parsed result
shown live in the Property Inspector as validation), then:

- **Press** to start or pause.
- **Press and hold** (~0.7s) to reset to the full duration.
- The key shows a **progress ring** that shrinks and shifts **green → amber → red** as time
  runs out.
- When the timer expires the key **flashes red** — press once to dismiss.
- Changing the duration resets the timer to the new full duration.

Because there are only six keys and no dial on a Mini, a single key owns the whole
interaction. It works on any Stream Deck (Mini, MK.2, XL, +) — the timer is a keypad action.

## How it works

The countdown is anchored to an absolute end timestamp that is persisted into the action's
settings, so a running timer keeps correct time across profile switches, page changes, and
Stream Deck restarts. The key face is drawn as an SVG (progress ring / flash frames) and
pushed with `setImage`; the ring color is interpolated per frame from the fraction of time
remaining. The label uses Stream Deck's **native Title field**, which the app composites on
top of the image — the plugin never draws text itself.

```
src/
  color.ts        # green → amber → red interpolation (pure)
  timer-model.ts  # state machine + time math (pure)
  render.ts       # SVG ring / flash-frame renderer (pure)
  actions/timer.ts# SingletonAction: controls + render/flash loops
  plugin.ts       # entry point
com.robodwyer.timer.sdPlugin/
  manifest.json   # action definition (Keypad controller)
  ui/timer.html   # Property Inspector (duration, with live parse readout)
  imgs/           # action / category / marketplace icons
  bin/            # build output (generated by `npm run build`)
test/             # unit tests for the pure modules (bun test)
```

## Requirements

- **Node.js 20+** to build (this repo builds cleanly on Node 20/22).
- **Stream Deck app 6.5+** to run the plugin.
- [`@elgato/cli`](https://www.npmjs.com/package/@elgato/cli) (installed as a dev dependency)
  for linking and live-reload.

## Develop & install locally

```bash
cd streamdeck-timer
npm install
npm run build        # bundles src → com.robodwyer.timer.sdPlugin/bin/plugin.js
npm run validate     # validates the manifest + plugin structure

# Install into the Stream Deck app and iterate with live reload:
npx streamdeck link com.robodwyer.timer.sdPlugin
npm run watch        # rebuilds and restarts the plugin on every change
```

Then, in the Stream Deck app: find the **Timer** category, drag **Timer** onto a key, and set
the **Title** (Stream Deck's built-in field at the top) and **Duration** in the Property
Inspector on the right. The duration accepts
plain-language input (`1h 30m`, `90s`, `5 min`) and shows the parsed result live beneath the
field so you can confirm it before running.

## Tests

```bash
npm test             # runs the pure-logic unit tests via `bun test`
```

The unit tests cover the color interpolation endpoints, the timer state machine and time
math, and the SVG renderer (arc geometry, flash frames). The interactive
behavior (press/hold gestures, render loop, flashing) is exercised on the device.

## Customizing

- **Colors / thresholds** — edit the endpoint colors and the split point in `src/color.ts`.
- **Timings** — `HOLD_MS`, `TICK_MS`, and `FLASH_MS` at the top of `src/actions/timer.ts`.
- **Ring geometry** — `RADIUS` and `STROKE` in `src/render.ts`.
- **Plugin / author id** — the reverse-DNS ids (`com.robodwyer.timer*`) appear in
  `manifest.json`, `package.json`, the `.sdPlugin` folder name, the `@action` UUID, and the
  `rollup.config.mjs` output path. Rename all of them together before publishing.

- **Default duration / bare-number unit** — the 5-minute fallback (`DEFAULT_MINUTES`) and the
  bare-number-as-seconds rule live in `parseDuration` in `src/timer-model.ts`.

> Note: the marketplace `Icon` is a PNG (required by the store); the action, category, and key
> images are SVG. The Property Inspector loads `sdpi-components` and `parse-duration` from CDNs;
> the plugin backend bundles `parse-duration` locally via rollup.
